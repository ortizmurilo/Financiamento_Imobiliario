# 🏠 Financiamento Imobiliário em Java

Projeto de simulação de financiamento imobiliário desenvolvido em Java, aplicando conceitos de Orientação a Objetos como encapsulamento, packages e modificadores de acesso.

---

## 📋 Funcionalidades

- Entrada de dados pelo usuário via terminal (valor do imóvel, prazo e taxa de juros)
- Validação dos dados informados
- Cálculo das parcelas do financiamento
- Organização do código em packages com responsabilidades separadas

---

## 📦 Estrutura do Projeto

```
src/
├── main/
│   └── Main.java           # Ponto de entrada da aplicação
├── modelo/
│   └── Financiamento.java  # Classe com os atributos e regras do financiamento
└── util/
    └── InterfaceUsuario.java  # Classe responsável pela interação com o usuário
```

---

## 🛠️ Tecnologias Utilizadas

- Java
- Orientação a Objetos (POO)
- Encapsulamento (getters e setters)
- Packages e modificadores de acesso (public e private)

---

## ▶️ Como Instalar e Executar

### Pré-requisitos
- [Java JDK 11+](https://www.oracle.com/java/technologies/downloads/) instalado
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) ou outra IDE Java

### Passos

1. Clone o repositório:
   ```bash
   git clone https://github.com/ortizmurilo/Financiamento_Imobiliario.git
   ```

2. Abra o projeto no IntelliJ IDEA:
   - `File → Open` e selecione a pasta do projeto

3. Execute o projeto:
   - Abra o arquivo `src/main/Main.java`
   - Clique no botão ▶️ ou pressione `Shift + F10`

4. Siga as instruções no terminal:
   - Informe o valor do imóvel
   - Informe o prazo do financiamento (em anos)
   - Informe a taxa de juros anual (%)
